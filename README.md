# cinderia-cheatsheet

แผ่นอ้างอิง **Cinderia** ฉบับเข้าใจถึงแก่น — A4 แนวนอน **หน้าเดียวจบ** พิมพ์ออกมาวางข้างจอได้เลย

📖 **[อ่านออนไลน์](https://tayakorn221.github.io/cinderia-cheatsheet/)**

---

## Why this exists

Cinderia อัปเดตถี่มาก — 11 เวอร์ชันย่อยใน 5 เดือน และ **V0.6.11 (14 ส.ค. 2026) ปรับเครื่องประดับรวดเดียว ~40 ชิ้น** พร้อมเพิ่มไอเทมใหม่ 37 ชิ้น

ผลคือไกด์เกือบทุกอันบนอินเทอร์เน็ต **ตกยุคทันที** ของที่เคยเป็นขยะกลายเป็นของดี (Fairy Wand โอกาสแปลงร่างศัตรู 12% → **100%**) และของที่เคยเป็นเสาหลักโดนถอดทิ้ง (Magic Lamp สเตตัส +6 → **0**)

แผ่นนี้เป็น **single source of truth** ที่ออกแบบให้เปิดดูตอนกำลังเลือกของกลางรัน — ไม่ต้องอ่าน ไม่ต้องเลื่อน แค่กวาดตาหาชื่อของแล้วดูว่าเลขมันขยับไปทางไหน

ตัวเลขทุกตัว **ดึงจาก patch notes ทางการโดยตรง** ไม่ได้ลอกต่อจากไกด์อื่น

## Quick Start

| อยากทำอะไร | ทำยังไง |
|---|---|
| ดูบนจอ | เปิด **[หน้าเว็บ](https://tayakorn221.github.io/cinderia-cheatsheet/)** — ย่อให้พอดีจอมือถืออัตโนมัติ |
| พิมพ์ / เซฟ PDF | กด **Ctrl + P** → Destination = *Save as PDF* → Save (ขนาดกระดาษถูกตั้งเป็น A4 landscape ใน CSS แล้ว ไม่ต้องตั้งเอง) |
| อ่านฉบับเต็มบนจอ | เปิด **[read.html](https://tayakorn221.github.io/cinderia-cheatsheet/read.html)** — ตัวหนังสือขนาดปกติ มีคำอธิบายละเอียดกว่า |
| เปิดออฟไลน์ | โหลด `index.html` ไฟล์เดียว เปิดได้เลย (ต้องต่อเน็ตครั้งแรกเพื่อโหลดฟอนต์) |

## เทคนิค

- **single-file HTML** ไม่มี framework ไม่มี build — เปิดจากไฟล์ตรง ๆ ได้
- **`@page { size: A4 landscape }`** ล็อกขนาดกระดาษใน CSS พิมพ์แล้วพอดี 1 หน้าจริง (ตรวจกับเบราว์เซอร์แล้ว: ใช้ 731 จาก 756 px ที่มี)
- **หน่วยเป็น `mm` / `pt` ทั้งแผ่น** ไม่ใช่ px — เพราะออกแบบเพื่อกระดาษก่อน จอทีหลัง
- **fit-to-width script** ~15 บรรทัด ย่อแผ่นให้พอดีจอเล็กด้วย `transform: scale()` แล้วยุบความสูง wrapper ตาม — ล้าง transform ทิ้งตอนพิมพ์
- **`print-color-adjust: exact`** บังคับให้สีแถบชั้น (เขียว/เหลือง/แดง) ติดตอนพิมพ์ ไม่โดนเบราว์เซอร์ตัดเป็นขาวดำ
- ฟอนต์: Fraunces (หัวข้อ) · IBM Plex Sans Thai (เนื้อหา) · IBM Plex Mono (ตัวเลข พร้อม `tabular-nums` ให้หลักตรงกัน)
